One sharp Monday-morning punchline: the alarm gives up, the coffee asks for a raise, and the 9 a.m. meeting turns out to be Monday introducing itself as the new boss. A single deterministic line about office life at the start of a long week, written to `entry.txt` by a pure standard-library Python program.

## Run it

```sh
python3 main.py
```

The program writes the punchline to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints the same line to stdout.
